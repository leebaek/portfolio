# 경기도 팜맵 120만 필지 통합·검수·집계

> 31개 시군으로 나뉜 팜맵(농경지 전자지도)을 하나의 GeoPackage로 통합·검수하고,
> 지역·농경지 유형별 필지 수와 면적을 집계했습니다.
> 집계 중 폐지된 법정동코드로 지역명이 누락된 11필지(2.56ha)를 찾아 보정했습니다.


## 1. 프로젝트 개요
- 역할: 개인 프로젝트
- 목적: 팜맵에서 제공하는 정보를 직접 수집해보고 싶었습니다.
- 사용 기술: Python, geopandas, pandas, QGIS, GeoPackage

## 2. 데이터
| 항목 | 내용 |
|---|---|
| 출처 | 공공데이터포털 (https://www.data.go.kr/data/15104483/fileData.do) |
| 범위 | 경기도 31개 시군 |
| 규모 | 1,186,446필지 |
| 좌표계 | EPSG:5179 (원본 시군별 좌표계가 달라 통일) |
| 보조 데이터 | 법정동코드csv (https://www.data.go.kr/data/15063424/fileData.do?recommendDataYn=Y&utm_source=chatgpt.com) |


## 3. 처리 흐름
1. **병합**: 31개 시군 shp(cp949)를 읽어 EPSG:5179로 통일 후 단일 GPKG로 저장
2. **전처리**: 필수 컬럼 선별 → 법정동코드를 시도/시군구/읍면동/리로 분해 → 법정동코드표 조인 → 분류코드를 명칭(논·밭·과수·시설·비경지)으로 변환
3. **검수**: PK 중복, 지오메트리 유효성·Null·Empty·면적 0 검사 (오류 레코드는 별도 파일로 저장)
4. **집계**: 시도 / 시군구 / 읍면동리 단위로 유형별 필지 수와 면적(ha) 산출
5. **이상 탐지·보정**: 지역명 누락 행 원인 분석 후 보정, 재집계

## 6. 주요 이슈와 해결
**폐지된 법정동코드로 인한 지역명 누락**
- 증상: 읍면동리 집계 CSV에 지역명이 빈 행 발생 (11필지, 2.56ha)
- 원인: 법정동코드 `4159710400`(폐지된 화성시 동탄구 오산동)이 법정동코드표에 없어 left join 결과가 결측
- 검증: QGIS에서 폴리곤 위치가 동탄구 여울동(`4159711500`)임을 확인
- 조치: 코드, 지역명, 주소, PNU 앞 10자리 수정 후 재집계
